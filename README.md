# Voll_med_API 🏥

API REST desenvolvida em **Java com Spring Boot** para gerenciamento de informações relacionadas a uma clínica/hospital.

O projeto está sendo desenvolvido durante um curso da **Alura**, acompanhando o conteúdo das aulas e aplicando os conceitos aprendidos na prática.

> 🚧 **Projeto em desenvolvimento:** novas funcionalidades e melhorias serão adicionadas conforme avanço no curso.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma API para realizar o gerenciamento de **médicos e pacientes**, colocando em prática conceitos de desenvolvimento de APIs REST utilizando Java e Spring Boot.

A aplicação permite realizar operações de **CRUD** (*Create, Read, Update e Delete*) sobre os dados cadastrados.

## ⚙️ Funcionalidades

Atualmente, o projeto conta com funcionalidades relacionadas ao gerenciamento de médicos e pacientes, como:

* 👨‍⚕️ Cadastro de médicos
* 🧑‍🤝‍🧑 Cadastro de pacientes

> As funcionalidades serão atualizadas conforme o desenvolvimento do projeto.

## 🔄 Operações CRUD

A API utiliza as operações HTTP para manipulação dos recursos:

| Método   | Operação | Descrição                   |
| -------- | -------- | --------------------------- |
| `POST`   | Create   | Cadastrar médicos/pacientes |
| `GET`    | Read     | Consultar médicos/pacientes |
| `PUT`    | Update   | Atualizar informações       |
| `DELETE` | Delete   | Excluir registros           |
